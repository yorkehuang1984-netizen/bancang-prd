关于这个项目
什么是"交互式 PRD"？

交互式 PRD 是一种比传统文档更直观的产品沟通方式。它不是可部署的 App，而是可点击、可交互的高保真原型， 让开发者、面试官或合作者直接在浏览器中体验产品逻辑，比静态 PRD 更生动，比开发 MVP 成本更低。

三种方式把这个项目放进简历

推荐方案一或方案二，可以获得一个真正的 URL 链接。

1
方案一：GitHub Pages（推荐）

免费、永久、支持自定义域名。在 GitHub 新建仓库 bancang-prd，上传整个项目文件夹，Settings → Pages → 选 main 分支 → 获得 username.github.io/bancang-prd 链接。

2
方案二：Netlify Drop（最简单）

打开 app.netlify.com/drop，把整个 板仓 文件夹拖进去，30 秒上线，获得 xxx.netlify.app 链接。无需注册命令行操作。

3
方案三：本地文件夹分享

把整个 板仓 文件夹压缩为 zip，对方解压后打开 index.html 即可浏览全部内容。适合通过微信/邮件发送给面试官。
